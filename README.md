# 慢慢说 · 字卡聊天

直接双击 `index.html` 即可打开，不需要安装依赖，也不需要联网。

## 操作

- 左上角三条杠：全屏功能页（字卡库、设置、决策历史）。
- **顶部对方头像右下角有加号**：点一下换对方头像，**双击是拍一拍**。
- 右上角三个点：更换我的头像、聊天设置。
- 底部加号：展开一条抽屉，一行四个入口（美化 / 决策 / 字卡库 / 设置），就这些。
- **决策**：底部加号 → 决策，打开「帮我抉择」弹层；填一个问题 + 2~10 个选项。
- 全屏菜单里的**决策历史**按日期分组（今天 / 昨天 / M月D日），可以回看，也可以清空。
- 输入后点发送，或按 Enter 发送；Shift + Enter 换行。
- **点任意气泡 → 弹操作菜单：复制 / 引用 / 删除**（自己的还有「撤回」，只能撤自己的）。撤回与删除是两回事：撤回只换显示，删除是真删。
- **引用**：菜单里选引用 → 输入区上方出现「引用 …」条 → 发送时带上；TA 回你时会按「TA 引用我消息的概率」偶尔引用你最近说过的话。
- 点自己发的气泡 → 菜单 → 撤回 → 站内弹层确认。
- 头部出现数字角标 = 你不在聊天页时 TA 发来了消息；回到聊天即清零。
- Escape 关闭弹层或返回上一页。

## 已实现的本地功能（都在浏览器本地，不联网）

### 聊天底盘

- **TA 会回你**：从字卡库抽 1~4 张拼成一句（张数可在设置里改），延迟默认 3~12 秒可调，回复前显示三点跳动的「正在输入」。
- **消息操作**：点气泡弹菜单——复制（复制不了会自动退回 execCommand）/ 引用 / 删除；自己的气泡多一条「撤回」。
- **引用是双向的**：我引用你在菜单里选「引用」，发送时把快照写进消息；TA 回复或主动找我时按「TA 引用我消息的概率」（默认 30%）引用我最近 8 条、30 分钟内的消息。点引用块可以看到引用的是谁的那句话。
- **已读 / 已读不回**：我方气泡下先显示「已送达」，约 0.9 秒后变「已读」；按「已读不回概率」（默认 20%）命中时 TA 只读到、不回你，并给一句提示。
- **撤回是双向的**：我方点自己的气泡 → 站内确认层 → 撤回；TA 撤回**先完整发出那句话，5 秒后**才收回（不是落库即撤）。撤回只是一条标记位（`rec`/`recBy`/`recAt`），正文与其它字段原样保留、记录条数不变；「显示撤回了什么」打开时，TA 的那条会写出撤回了什么。撤回 ≠ 删除。
- **拍一拍也是双向的**：双击对方头像（顶栏或消息旁的都行）→ 灰色系统条。用语来自字卡库里可编辑的「拍一拍动作池」。三概率默认 **回拍 40 / 回复变拍 20 / 主动变拍 20**；命中时那一整条消息变成拍一拍。动作池为空时退回普通消息。
- **主动消息**：按「最短~最长间隔」（默认 30~90 分钟）自己来找你；不在聊天页时记未读 + 角标 + 提示。

### 字卡库

- **一个范围，两个分区**：顶部「字卡 / 拍一拍」两颗 tab —— 字卡就是这一套（单梦角，不再分公共和专属），点「拍一拍」切到动作池。
- **四颗按钮一行排在分组条上面**：新建分组、分组设置、导出字卡、导入字卡。
- **分组固定为一排可横向滑动的 tab 条，第一颗是「全部」**（单选，不退成下拉、不纵向折叠）。
- 单张新增、逐行批量新增（空行跳过、重复去重）、编辑、删除；搜索。
- **导出字卡 / 导入字卡**：导出是本站自有 JSON（全部分组与字卡）；导入认本站备份与 milk 的字卡文件，只取字卡、分组与拍一拍动作池，其余字段静默忽略，导入前确认一次，同名分组并进去、重复字卡跳过。
- 新建 / 改名 / 隐藏 / 删除分组。隐藏的分组不参与 TA 抽卡，字卡仍在库里可找回。删分组时问清楚：「**只删分组**」（组内字卡移进同范围的「未分组」，不丢）还是「**连字卡一起删**」。
- 「拍一拍」分区就是动作池，可增可删。

### 设置

- **基础资料**：我的昵称 / 对方昵称；我的头像 / 对方头像（可上传更换、可恢复默认）。换完顶栏、菜单和**聊天记录里每条消息旁的头像**一起换，不用刷新。
- **聊天背景**：上传更换、恢复默认，**只作用在聊天消息区**，不污染整站背景。
- **「聊天底盘」大标题下连着三组**：回复节奏（回复延迟、拼字卡张数、已读不回概率、TA 引用我消息的概率）、拍一拍（三概率）、撤回（TA 撤回概率、显示撤回了什么）。
- **「功能模块」大标题下**：主动消息（开关 + 间隔区间）、数据管理（导出字卡时是否带上拍一拍动作池、导出备份 / 导入备份 / 清空重来）。
- 概率与区间用滑杆，开关用拨动；**0 是「关闭」，会被尊重、不回落默认值**。改动即时保存。

### 决策（帮我抉择）

从聊天「更多功能」打开一个弹层，不是单独的功能页：

- 填一个**问题**（最多 100 字）+ **2~10 个选项**（每个最多 50 字）。初始给两个选项，可增可删；问题为空或有效选项不足时，两个按钮都点不动。
- **开始抉择**：用安全随机（优先 `crypto.getRandomValues`，没有才退回 `Math.random`）抽一个选项，弹层立刻换成结果态显示「命运之选」，同时把这次「问题 / 全部选项 / 结果 / 时间 / 模式」记进抉择历史。**是否发到聊天由你决定**——不点「发送到聊天」就只留在自己的历史里。
- **让 TA 帮我定**：弹层收起、回到当前聊天，先发一张**不显示结果**的「请帮我选」卡（带问题和全部选项），TA 在 2~5 秒后回一句「我的建议是：X」。
- 结果态还有「再来一次」（同题重掷并再记一条）和「改一下问题和选项」。弹层底部可展开「历史记录」（最近 20 条）。
- **决策历史**（全屏菜单）按日期分段：今天 / 昨天 / M月D日，每条显示时间、问题、结果、是「命运之选」还是「TA 的建议」、以及当时的全部选项；「清空历史」要点确认。历史最多 50 条，按梦角（cid）隔离。旧版本只存了「问题+结果」的历史会自动迁进来，不会丢。
- 历史是给回看和管理用的，不会重新发到聊天。

### 原有的本地演示

美化页：背景 / 字号 / **气泡皮肤（六套内置，含实时预览）** / **自定义气泡 CSS（可写、可贴、可上传 .css 文件）**。

## 气泡皮肤与自定义 CSS

### 六套内置皮肤

经典 / 圆润 / 信纸 / 雾面 / 墨线 / 药丸。在「美化」页第一屏，选中的那颗描一圈，下面的预览是**真实的聊天骨架**
（同样的 `.message-row` / `.bubble` 类名），所以预览里看到的和聊天里完全一致。

### 时间分隔条

聊天最上面不再是「一段对话的开始」，而是一条**时间分隔条**：上面是繁体 **未讀信息**，下面是 `10月29日 11:37`。

规则：第一条消息前一定有一条；之后**双方静默满 30 分钟**再来消息，就在那条消息上方再插一条（29 分钟不插，正好 30 分钟插）。

分隔是渲染时按相邻两条消息的时间差现算的（`gapFlags`），不写进消息里 —— 所以：

- 老记录升级后立刻有分隔，不用迁移数据；
- 删掉一条消息，分隔会跟着重算，不会留下孤儿；
- 改系统时间 / 换时区也不会把分隔弄重复。

### 自己上传 CSS

三条路都通：在弹层里写、把别处抄来的一整段贴进去、或者传一个 `.css` 文件。规则：

- **只写声明**（整段没有 `{`）→ 自动套到双方气泡上，并由应用替你补 `!important`；
- **写选择器** → `.bubble` 气泡、`.message-row.self` / `.message-row.peer` 是我 / 对方那一行、`.message-avatar` 头像；
- 外面抄来的 `.msg-bubble` / `.msg-in` / `.msg-out` / `.message-sent` 这些类名会**自动映射**到站内（不映射的话贴进来等于没贴）；
- 每条规则自动加 `#app` 作用域，特异性压过站内样式，**不带 `!important` 也能生效**；
- `@import` 与 `html` / `body` / `:root` 会被清掉；`url("https://…")` 的挂件放行（要联网），想离线自带请用 `data:` 图；
- 上限 8000 字符。

两套样式挂成两个独立 `<style>`：`#bubble-skin` 在前、`#bubble-css` 在后 —— 同特异性下后写的胜，
所以**自己的 CSS 永远盖在内置皮肤上面**。

## 升级说明（从旧版存档）

旧存档里如果有「专属字卡」那一套，**不会被丢掉**：打开时会自动并进同一套——同名分组并在一起，
同一句话只留一张，专属独有的分组原样保留，并完变成空壳的组直接去掉。所以升级后不会凭空多出两组「未分组」。

## 数据

只保存在当前浏览器的 localStorage，键名 `slowly-chat-order42-v1`。默认消息、字卡与拍一拍动作池是出厂种子；用户删光的内容刷新后不会自己长回来。头像与聊天背景走 canvas 压缩后随存档保存，不上传服务器，限制原图 5MB。不同浏览器、无痕模式或更换打开方式不会共享数据。

## 范围边界

- TA 的回复来自**本地字卡库**，不是联网 AI；没有在线/正在输入的人设宣称（「正在输入」只是本地延迟过渡）。
- 本轮未接：决策里的「向我提问」（梦角反向提问 + 提高概率，属第21单 B 段）、问卷（`features/quiz` 的另一半）；消息引用＋复制（`features/quote`）、朋友圈、表情包、信件、原生通知与转 APP。
- **本轮没做**：工单第21单 B 段「向我提问」、问卷、朋友圈、表情包、信件、纪念日、一起听、原生通知与转 APP（同前）。
- 本轮补齐的项里，**软键盘抬升只有 visualViewport 的代码路径，没有真机验证**；剪贴板在 `file://` 下会退回 `execCommand`，是否真的写进系统剪贴板也没有在真机上验过；字卡导出在 Android WebView 里 `<a download>` 可能被静默忽略（工单第2单#5 记过这个坑），本单是网页版，导出通道没做 Capacitor 分支。
- 详细接入记录见 [_docs/接入报告.md](_docs/接入报告.md) 与 [_docs/复用回流.md](_docs/复用回流.md)。
